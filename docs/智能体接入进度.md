## 二、关键成果

### 2.1 三个原有 Bug 已修复

**P0-1 首次评价失败**
`dish_review.rating` 是 `NOT NULL` 无默认值，原代码先 insert 再赋值 → 严格模式报错。
已改为 insert 前赋值。

**P0-2 删除后无法再评**
唯一键 `uk_dish_user` + 逻辑删除，记录占位导致 insert 撞键。
已加 `selectOneIncludeDeleted` + `restoreAndUpdate` 复活历史记录。

**P1 收藏状态失效**
白名单路径被 `excludePathPatterns` 跳过拦截器，`UserContext` 恒空。
已改为「可选登录」：白名单也解析 token 填身份。

### 2.2 智能体已接入

- 模型：`Qwen/Qwen2.5-7B-Instruct`（硅基流动）
- 7 个工具全部实时查库，数字不经过模型记忆
- 卡片数据取自工具原始结果，不取自模型输出
- 降级链：LLM → 规则引擎 → 兜底

## 三、七个踩坑（答辩可讲）

1. **结构化提示词让 7B 只说话不调工具** → 改紧凑自然语言
2. **带历史时 30%~50% 概率忘调工具直接编造** → `tool_choice=required` 强制兜底 + 独立 summarize
3. **模型推测工具没返回的属性**（辣不辣）→ 提示词明确"没写就说没写"
4. **模型输出 Markdown 符号** → 提示词 + 代码 `sanitize()` 双保险
5. **「13号窗口」查不到** → 窗口号归一化
6. **知识库检索先到先得导致答非所问** → 打分排序
7. **知识库无匹配时乱给条目** → 返回空 + hint

详见 [智能体测试报告.md](智能体测试报告.md)。

## 四、如何运行

```bash
# 1. MySQL（你已启动）
net start MySQL80

# 2. 后端
cd canteen-backend && mvn spring-boot:run

# 3. 前端
cd canteen-frontend && npm run dev
```

访问 http://localhost:5173，用 `student01 / 123456` 登录，点右下角悬浮球。

**切换纯规则引擎**：把 `application.yml` 的 `canteen.agent.enabled` 改成 `false`。

## 五、演示建议

### 最能打动人的三个演示

1. **新数据识别**：现场插一道菜 → 立刻问智能体 → 准确报出价格
   ```sql
   INSERT INTO dish(stall_id,name,price,category,featured,status,create_time)
   VALUES(1,'演示新菜',9.9,'荤菜',0,1,NOW());
   ```
   然后问「演示新菜多少钱」

2. **多轮指代**：问「宫保鸡丁多少钱」→「它在哪个窗口」→「这家还有什么菜」

- 多条件组合筛选（"比宫保鸡丁便宜且评分更高的菜"）

### 演示前检查

跑一遍测试报告的 15 个问题，确认网络/Key/MySQL 正常。
